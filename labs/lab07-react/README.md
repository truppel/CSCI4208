# Lab 01: React — Interactive Story SPA

This lab introduces React by refactoring a multi-page HTML adventure game into
a React single-page application (SPA).

Students preserve the original story, choices, inventory, shop, combat, and
win/lose paths while learning how React changes the application's
architecture. Instead of loading a separate HTML document for every scene and
passing inventory through URL parameters, the finished app renders scene
components and stores shared game state in React Context.

## Prerequisites

Students should be familiar with:

- HTML elements and attributes
- Links, forms, images, audio, and video
- JavaScript functions and event handlers
- URL query parameters
- Basic terminal commands

No previous React experience is required.

The lab uses:

- Node.js `20.19.0` or newer in the Node 20 line, or Node.js `22.12.0`
  or newer
- npm
- React
- Vite
- A modern browser and code editor

## What Students Build

The completed project is an interactive React adventure game with:

- Component-based story scenes
- SPA navigation without loading separate HTML documents
- Shared inventory and navigation state through Context
- Reusable page, navigation, inventory, and death-screen components
- Local state for scene-specific interactions
- Shop purchases and persistent inventory updates
- Goblin combat with victory and game-over branches
- A controlled Dungeon form
- Image, audio, and video content
- A production build generated by Vite

## Concepts Covered

The tutorial introduces concepts incrementally:

1. Node.js, npm, Vite, and the React project structure
2. JSX and function components
3. Props, event handlers, and local state
4. SPA page selection
5. Context and shared state
6. Reusable components, props, and children
7. Conditional rendering
8. Coordinating local and shared state
9. Declarative media
10. State transactions for purchases and combat
11. Controlled forms
12. Regression testing and production builds

Each goal includes a Design, Apply, and Assess phase. Students should complete
the assessment and confirm the app still runs before moving to the next goal.

## Running the Verification Project

```bash
cd gameapp
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

Vite writes the generated site to `gameapp/dist/`.
